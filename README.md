# Sistema_Chamados
Sistema de gerenciamento de chamados de TI voltado ao suporte técnico corporativo, desenvolvido com o objetivo de aplicar e consolidar conhecimentos adquiridos em Java nos últimos meses. Projeto de caráter educacional, desenvolvido para aprofundar os conhecimentos em JDBC e banco de dados com um pouco de JPA, servindo como base para uma futura atualização utilizando mais funcionalidades de JPA e Spring.
